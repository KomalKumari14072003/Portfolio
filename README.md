# Komal Kumari | Portfolio

A responsive personal portfolio website for **Komal Kumari**, a Full Stack Developer. It presents professional experience, technical skills, selected projects, education, certifications, contact links, and a downloadable resume.

## Live website

After GitHub Pages is enabled, the site will be available at:

`https://komalkumari14072003.github.io/Portfolio/`

## Highlights

- Responsive single-page portfolio design
- Sections for about, experience, skills, projects, education, certifications, and contact
- Featured projects: Ayushmantra, NiviApp, and BdayFy
- Resume download
- Mobile navigation and smooth scrolling

## Tech used

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts
- Font Awesome

## Run locally

No installation or build step is required.

1. Clone the repository.
2. Open `index.html` in any modern browser.
